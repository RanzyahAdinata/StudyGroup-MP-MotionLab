# Task-Contact ✨

Aplikasi **CRUD Kontak** sederhana yang memanfaatkan **Core Data** untuk menyimpan dan mengelola informasi kontak. Project ini dirancang untuk membantu memahami dasar-dasar implementasi Core Data pada aplikasi iOS.

## Fitur 📋
- Tambah kontak baru ➕
- Lihat daftar kontak 👀
- Edit informasi kontak ✏️
- Hapus kontak ❌
